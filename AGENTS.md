# Orbit Nest

Use English in source, documentation and repository artifacts. Keep this repository separate from orbit-app. Shared scheduling and execution durability belongs in cybergarage/orbit. Preserve native renderer sandboxing and validate IPC commands. No unrestricted shell, filesystem, network or model tools. No cloud fallback, model downloads, external sending, purchases, daemon or login item. Use synthetic fixtures for testing and screenshots. Run lint, types, unit, native UI and build checks before delivery. Pin core package source and checksum; never publish it to npm or merge core automatically. External file writes require a separate proven approval boundary. Plaintext user state is separate from Git.

## Research and decisions

Follow [the research management guide](docs/research/README.md) and [decision-record convention](docs/decisions/README.md). Keep English public research in studies dated by their original UTC start date, retain completed studies, and record the date and reason for factual corrections. Keep product hypotheses proposed until explicitly accepted; research merges do not accept them, and accepted does not mean implemented.
