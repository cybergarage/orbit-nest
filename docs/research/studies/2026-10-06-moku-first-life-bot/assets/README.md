## Reproduce

From the repository root, run `node docs/research/studies/2026-10-06-moku-first-life-bot/assets/render.cjs`. Uses the existing Playwright dependency and installed Chrome on macOS; `MOKU_BROWSER_PATH` can select another already-installed Chromium executable. No external resources or downloads are needed. The current left-navigation revision captures the viewport shell; long content scrolls independently in the work pane. Previous tall screenshots remain in Git history. Buttons and filters are inert; navigation links switch concept pages and the narrow Bot-work anchor reaches its labelled sidebar.
