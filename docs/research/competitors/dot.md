# Dot (OpenAI)

Observed: 2026-10-04 UTC / 2026-10-05 JST. Product build unknown. At retrieval, D1 displayed “19 hours ago” and D2 “4 days ago” as update ages. Evidence: documented. No hands-on product test.

## Facts

[D1] Users can set a name, avatar and character/pet, then request work or recurring checks in conversation. The profile shows In progress / Scheduled / Completed. Dot has a cloud computer; local access is optional and initially off.

[D2] Activity View includes delegated tasks. Custom Rules, plugin permissions and Auto-review govern boundaries. Individual dot memories cannot currently be directly edited or deleted.

## Evaluation

A conversational entry point for recurring work, followed by activity and schedule review, is useful comparison material. Delegation is documented, but does not establish a user-managed multi-Dot library or global Kanban. Memory correction is a distinction that a simple “has memory” comparison would miss.
